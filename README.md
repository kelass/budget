# Бюджет

Учёт расходов и бюджет на месяц для iPhone. Устанавливается из Safari на экран «Домой», работает без интернета, все данные хранятся на телефоне в базе SQLite. Сервера с данными нет.

## Установка на iPhone
1. Откройте ссылку на приложение в Safari.
2. «Поделиться» → «На экран Домой» → «Добавить».
3. Открывайте иконкой «Бюджет».

## Устройство кода
- `src/domain.js` — бизнес-правила: период, остаток, «можно в день», обязательные платежи, деньги в минорных единицах.
- `src/infra.js` — SQLite (sql.js / WebAssembly), сохранение файла базы в IndexedDB, миграции, репозитории.
- `src/services.js` — сценарии использования и модели для экранов.
- `src/ui.js` — экраны по макету.
- `src/pwa.js`, `src/sw.js` — установка, офлайн-кэш, обновления.

## Сборка
```
npm install
python3 build_pwa.py   # устанавливаемая версия → docs/ (публикуется GitHub Pages)
python3 build.py       # одностраничная симуляция → dist/budget.html
```
