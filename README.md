# Бюджет

Учёт расходов и бюджет на месяц для iPhone. Приложение ставится из Safari на экран «Домой», работает без интернета и хранит все данные только на телефоне — в настоящей базе SQLite. Сервера с данными нет, регистрации нет, ничего никуда не отправляется.

**Открыть приложение:** https://kelass.github.io/budget/

## Установка на iPhone

1. Откройте ссылку выше в **Safari**.
2. Нажмите «Поделиться» на панели Safari.
3. Выберите «На экран Домой» и нажмите «Добавить».
4. Открывайте приложение иконкой «Бюджет».

Магазин приложений, Mac и аккаунт разработчика Apple не нужны. Если ссылка открылась внутри Telegram или другого приложения, выберите «Открыть в Safari».

## Что умеет

- **Обзор месяца.** Сколько осталось, сколько можно тратить в день, чтобы дотянуть до конца месяца, сколько потрачено сегодня. Отметка на полосе показывает, какая часть месяца уже прошла.
- **Обязательные платежи.** Аренда, накопления и другие обязательные траты со сроком. Галочка ставится сама, когда записей в категорию набралось на нужную сумму. Напоминание появляется заранее.
- **Быстрый ввод.** Сумма с цифровой клавиатуры, категория, дата и заметка. Ещё до сохранения видно, как изменится лимит.
- **История.** Записи по дням, поиск по заметкам, фильтр по категориям, редактирование и удаление.
- **Аналитика.** Расходы по дням, за полгода и за год, сравнение с бюджетом, структура по категориям и разница с прошлым месяцем.
- **Бюджет и лимиты.** Общий бюджет и лимиты категорий; новый месяц начинается с лимитов прошлого. Начало месяца можно перенести на день зарплаты.
- **Валюта.** Рубль, доллар, евро, злотый, тенге, гривна, белорусский рубль, лари.
- **Резервная копия.** Файл базы можно сохранить в «Файлы» или отправить себе в Telegram и восстановить на новом телефоне.

## Приватность

Все записи хранятся в файле базы SQLite внутри приложения на вашем телефоне. GitHub Pages только раздаёт файлы программы при первом открытии и при обновлениях. Приложение не делает сетевых запросов с вашими данными, не использует аналитику и рекламу.

Данные живут в хранилище установленного приложения. Если удалить иконку с экрана «Домой», данные удалятся вместе с ней, поэтому время от времени делайте резервную копию в настройках.

## Как это устроено

Это PWA — веб-приложение, которое iOS позволяет установить на экран «Домой» как обычное. После первого открытия все файлы сохраняются на телефоне, и дальше интернет не нужен.

| Часть | Технология |
|---|---|
| База данных | SQLite, скомпилированный в WebAssembly ([sql.js](https://github.com/sql-js/sql.js)) |
| Хранение файла базы | IndexedDB на устройстве, сохранение пачкой через 400 мс и при сворачивании |
| Офлайн-работа | Service worker с кэшем всех файлов, версия по хэшу содержимого |
| Интерфейс | Чистый JavaScript без фреймворков, шрифт Onest внутри приложения |

### Слои кода

Код разделён по принципам предметно-ориентированного проектирования: правила бюджета не знают ни про базу, ни про экраны.

```
src/
  domain.js    правила: период, остаток, «можно в день», обязательные платежи, деньги
  infra.js     SQLite, хранилище, миграции схемы, репозитории, демо-данные
  services.js  сценарии использования и модели для экранов
  ui.js        экраны, листы, ввод
  pwa.js       экран установки, офлайн-кэш, обновления
  sw.js        service worker
docs/          собранное приложение, которое публикует GitHub Pages
```

### Схема базы

```sql
settings        (key, value)
categories      (id, name, color, sort, is_mandatory, due_day, remind_days, archived)
budgets         (period, total)                       -- period = 'YYYY-MM'
category_limits (period, category_id, amount)         -- для обязательной: сумма к внесению
expenses        (id, category_id, amount, spent_at, note)
```

Суммы хранятся целыми числами в копейках (центах), чтобы не было ошибок округления. Даты — строки `YYYY-MM-DD HH:MM` в локальном времени, по ним построены индексы. Версия схемы — в `PRAGMA user_version`, миграции применяются при запуске.

## Сборка

Нужны Node.js и Python 3 с Pillow.

```bash
npm install
python3 build_pwa.py   # устанавливаемое приложение → docs/
python3 build.py       # одностраничная симуляция → dist/budget.html
```

Чтобы опубликовать изменения, достаточно закоммитить обновлённую папку `docs/` в ветку `main`: GitHub Pages раздаёт её автоматически, а у пользователей появится плашка «Доступна новая версия».
